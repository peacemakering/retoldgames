# 遊戲劇情重述

完整重述遊戲主線劇情，讓沒有時間遊玩的人，也能以第一身走過一次故事。(中文優先)

## 從這裡開始
- 想知道我為甚麼寫這些文章 → [理念與方法](docs/ideas-and-approach.md)
- 想直接讀文章 → [文章一覽](#文章一覽)

## 這是甚麼

- 有完整的劇情流程，但不寫成機械式攻略。
- 保留關鍵對白與氣氛，讀者可以自行控制閱讀節奏。
- 每章只包含該章為止的內容，讀到哪裡都不會被後面的劇情破壞。

## 這是甚麼，不是甚麼

不是攻略（不逐項列操作步驟），不是小說（不為一個場景寫幾百字形容），
不是官方出版物。

## 寫作原則

內容依據遊戲原有內容, 網上資料, 對白文本, and/or官方資料整理，經AI核對/查証。發佈前一般會經人工鑑賞。呈現內容盡量忠於遊戲原有內容
（詳細方法見 [理念與方法](docs/ideas-and-approach.md)。）
